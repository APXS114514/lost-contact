# 失联 · 深夜 23:53（Lost Contact）

一个以 **macOS 桌面** 为载体的网页解密游戏。

你打开了一台已经一个月没有人登录的电脑。在 QQ、微信、备忘录、照片、语音备忘录等应用里寻找蛛丝马迹，收集证据，还原“失联”前夜发生的真相。

> 本项目为 **AI 辅助创作**，仅用于 **个人练习与学习**，不用于商业用途。

---

## 玩法介绍

1. 打开 `index.html`，等待系统启动并进入登录界面。
2. 输入密码，进入“他”的电脑。
3. 在桌面中探索各种应用：
   - QQ 群聊
   - 微信聊天
   - Safari 浏览器
   - 备忘录
   - 照片
   - 语音备忘录
   - 新闻
   - 废纸篓
   - 报告
4. 从聊天记录、图片、音频和网页中收集线索与证据。
5. 破解密码、解码信息，逐步接近“失联”事件的真相。
6. 根据你的探索进度与选择，走向不同的结局。

> 温馨提示：第一次游玩建议不要打开 `story.js`，避免剧透。

## 技术栈

- 纯原生 **HTML + CSS + JavaScript**
- 无框架、无构建步骤
- 所有资源本地化（`assets/`），可离线运行
- 模拟 macOS 桌面交互：窗口系统、Dock、菜单栏、开机启动等

---

## 运行方式

### 方式一：直接打开

直接双击 `index.html` 即可在浏览器中运行。

### 方式二：本地静态服务器（推荐）

```bash
python -m http.server 8080
```

然后访问：

```
http://localhost:8080
```
